# Pgsql, Mysql, SQL Server

| **Đặc điểm**         | **MySQL**                                                                                                           | **PostgreSQL**                                                             | **SQL Server**                                                        |
| -------------------- | ------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| **Mô hình**          | Relational (Quan hệ)                                                                                                | Object-Relational (Đối tượng-Quan hệ)                                      | Relational (Quan hệ)                                                  |
| **Bản quyền**        | Open Source (Oracle)                                                                                                | Open Source (Cộng đồng)                                                    | Thương mại (Microsoft)                                                |
| **Chi phí**          | Miễn phí (Community)                                                                                                | Miễn phí hoàn toàn                                                         | Trả phí cao (có bản Express free)                                     |
| **Thế mạnh**         | Đọc dữ liệu nhanh, dễ dùng                                                                                          | Xử lý dữ liệu phức tạp, tính năng cao cấp                                  | Bảo mật, tích hợp hệ sinh thái .NET                                   |
| **Khả năng mở rộng** | Tốt cho ứng dụng web                                                                                                | Rất tốt cho hệ thống lớn                                                   | Rất tốt cho doanh nghiệp                                              |
| **Hệ điều hành**     | Đa nền tảng                                                                                                         | Đa nền tảng                                                                | Windows (chủ yếu), Linux                                              |
| More                 | Thiết kế đơn giản, phù hợp hệ thống có business logic đơn giản.<br>Read write nhanh, setup đơn giản. Cộng đồng lớn. | Cung cấp nhiều chức năng. Tối ưu JOIN, Query với MVCC, nhiều kiểu dữ liệu. | Dự án lớn. Hệ sinh thái mạnh. SSMS, Power BI. OS window. Chi phí cao. |
