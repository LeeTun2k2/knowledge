# Behavior interview

## Interviewer expectation

Interviewer want to know:
- How you think
- How you work
- How you collaborate
	In real world scenarios.

## Key concepts

- Teamwork & collaboration -> can work well with others?
- Problem solving -> How to handle challenges or unexpected issues?
- Communication -> Can you convey ideas clearly?
- Adaptability -> How you respond change, ambiguity, or setbacks?
- Leadership and initiative -> Can you take ownership and drive progress forward?
- Work ethic and value -> -Are you reliable, accountable, and aligned with company culture?
